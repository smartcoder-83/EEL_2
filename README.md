# EEL2 – Smile NGO UI/UX Design Project

This repository contains the deliverables and resource links for our **EEL 2 (Engineering Exploration Lab 2)** group project at **MMCOE**.

The project focuses on designing a modern **UI/UX prototype in Figma** for the non-profit organization **Smile**, with an emphasis on usability, accessibility, and user-centered design.

## Project Overview

- **Project Title:** App for a Non-Profit Organization "Smile"
- **Course:** Engineering Exploration Lab 2 (EEL 2)
- **Semester:** Second Semester
- **Design Tool:** Figma

> **Note:** This repository serves as a central place to access the project resources. The actual design files are hosted on Figma.
